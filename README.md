# BackupLinux 🐧

Repositorio privado de backup y automatización para mi setup personal de **CachyOS + KDE Plasma**.

---

## ¿Qué hay aquí?

| Carpeta | Contenido |
|---|---|
| `linux/configs/` | Dotfiles: fastfetch, konsole, widget del reloj |
| `linux/fonts/` | Fuentes personalizadas: Fredoka, Okami, Earth Theory |
| `linux/scripts/` | Scripts de yt-dlp y utilidades |
| `gaming/notes/` | Configuraciones de juegos y parámetros de Steam |
| `gaming/mc_skins/` | Skins de Minecraft |
| `assets/` | Wallpapers e iconos |
| `docs/` | Guías de reinstalación |

---

## Reinstalación rápida

```bash
git clone https://github.com/tuusuario/BackupLinux.git
cd BackupLinux
chmod +x setup.sh
./setup.sh
```

> Ver `docs/` para la guía completa de reinstalación de CachyOS.

---

## Notas
- El script `setup.sh` automatiza la instalación de paquetes, dotfiles y fuentes.
- Los archivos sensibles (contraseñas, tokens) **nunca** se suben a este repo.
