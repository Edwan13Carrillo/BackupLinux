Fase 1 — Instalación y Particionado
⚠️  Crucial para que systemd-boot funcione correctamente.

1.1 Tabla de particiones
    • Tipo de tabla: GPT
1.2 Partición EFI
    • Tamaño: 2048 MiB
    • Sistema de archivos: FAT32
    • Punto de montaje: /boot
    • Flag: boot
1.3 Partición raíz
    • Tamaño: resto del disco (~236 GB)
    • Sistema de archivos: Btrfs
    • Punto de montaje: /
1.4 Contraseñas
    • Usar contraseñas diferentes para Usuario y Administrador (root)

Fase 2 — Configuración Post-Instalación (CachyOS Hello)
2.1 Ajustes de optimización
    • Ananicy Cpp: Habilitado — prioridad de procesos para gaming
    • Cachy Update: Habilitado
    • Systemd-oomd: Deshabilitado — evita que el sistema mate juegos pesados por error
    • Bpfutune: Deshabilitado
    • Bluetooth: Habilitado
2.2 Utilidades iniciales
    • Evaluar espejos (Mirrors): para máxima velocidad de descarga en Colombia
    • Instalar paquetes de gaming: dependencias de Wine, drivers y Proton

Fase 3 — Configuración de almacenamiento "Game Zone"
Ejecutar antes de instalar juegos para evitar fragmentación y proteger el sistema:

# Crear subvolumen optimizado
sudo btrfs subvolume create /games
sudo chattr +C /games    # Desactiva Copy-on-Write (NoCoW) para rendimiento
sudo chown $USER:$USER /games    # Permisos para el usuario

Fase 4 — Sistema de snapshots (Snapper)
4.1 Instalación
sudo pacman -S snapper snapper-support btrfs-assistant
4.2 Configuración
Crear config root y ajustar límites en /etc/snapper/configs/root:
    • DAILY: 5
    • WEEKLY: 1
    • El resto en 0
4.3 Snapshot maestra
snapper -c root create --description "Sistema base configurado"
💡 Hacer esta snapshot justo cuando el sistema base esté listo y antes de instalar juegos.

Fase 5 — Aplicaciones
5.1 Repositorio oficial de CachyOS (pacman)
sudo pacman -S discord protonvpn vlc telegram-desktop zen-browser-bin git fastfetch base-devel yay

Prism Launcher (con Java 17):
sudo pacman -S prismlauncher
⚠️  Al configurar Prism Launcher, seleccionar Java 17 en Ajustes > Java.
5.2 AUR (via yay)
Visual Studio Code con sincronización oficial de GitHub:
yay -S visual-studio-code-bin
5.3 Flatpak
Sober (Roblox):
flatpak install sober
5.4 Fuentes
Copiar los archivos .ttf a la carpeta de fuentes del usuario:
cp Fredoka-Medium.ttf Okami.ttf EarthTheory.ttf ~/.local/share/fonts/
fc-cache -fv

Fase 6 — Konsole
6.1 Perfil
Copiar la carpeta del perfil guardado:
cp -r MiPerfil.profile ~/.local/share/konsole/
En Konsole: Ajustes > Gestionar perfiles > seleccionar el perfil y marcarlo como predeterminado.
6.2 Configuración del perfil
    • Shell: fish (ya viene por defecto en CachyOS)
    • Aspecto: difuminar fondo 72%, escritorio 0%
    • Desplazamiento: barra oculta
6.3 Fastfetch
cp -r fastfetch/ ~/.config/fastfetch/
⚠️  Verificar que el archivo config.jsonc esté presente con el logo y orden personalizado.
6.4 Atajo de teclado
Ajustes del sistema > Atajos de teclado > agregar atajo Meta+T para lanzar Konsole.
